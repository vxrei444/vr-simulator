## エディター
Unity 6000.0.77f1を使用
モジュールのAndroid Build SupportとOpenJDKとAndroid SDK & NDK Toolsを追加すること。
Microsoft Visual Studioは任意。
VSCodeとか入っているなら代用

GitHubDesktop使用推奨

## 作業ルール
作業では必ず以下を守ってください。
- ブランチを切ること
- 作業をする際は他の人のフォルダを決していじらないこと。
- ファイルを移動したい場合はコピーして移動すること。
- 自分のフォルダ配下で作業すること。


## セットアップ
リポジトリをローカルへクローンする
UnityHubを開き、プロジェクトの追加、ディスクから追加するでローカルでクローンしたフォルダを選択する。

## 新しく作業を開始する際
1. 作業するための作業ブランチを切る（枝分かれさせる。名前は実装するタスク名にする）
2. 作業ブランチに必ず移動した上で作業する
3. 作業を終了する場合、Unity上でsave sceneかつsave projectを行いUnityを完全に閉じる。
4. GitHubにCommit、Pushする。


## 作業再開時
1. 作業ブランチをmainブランチで最新の情報に更新する（コンフリクト、エラーみたいなのがでたら要相談）
2. 作業ブランチに必ず移動した上で作業する
3. 作業を終了する場合、Unity上でsave sceneかつsave projectを行いUnityを完全に閉じる。
4. GitHubにPushする。
